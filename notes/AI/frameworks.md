## NumPy
<!-- junior 3525480 -->
Работа с многомерными массивами и матрицами + математические функции.

Основные преимущества:
- Высокая производительность (написана на C)
- Векторизованные операции (работа с целыми массивами без циклов)
- Линейная алгебра, случайные числа, преобразование Фурье

```python
import numpy as np

""" 1. Создание массивов """
arr = np.array([1, 2, 3, 4, 5])
matrix = np.array([[1, 2, 3], [4, 5, 6]])

""" 2. Математические операции """
arr = arr * 2  # Умножение всех элементов
result = np.sin(arr)  # Синус каждого элемента

""" 3. Генерация данных """
zeros = np.zeros((3, 3))  # Матрица 3x3 из нулей
random_nums = np.random.rand(5)  # 5 случайных чисел

""" 4. Индексация и срезы """
print(arr[arr > 5])  # Фильтрация

""" 5. Линейная алгебра """
a = np.array([[1, 2], [3, 4]])
b = np.array([[5, 6], [7, 8]])
dot_product = np.dot(a, b)  # Матричное умножение
```

## Pandas
<!-- junior 3525480 -->
Анализ и обработка табличных данных.

Основные преимущества:
- Удобные структуры данных (DataFrame, Series)
- Работа с пропущенными значениями
- Группировка, агрегация, объединение данных
- Чтение/запись различных форматов (CSV, Excel, SQL)

```python
import pandas as pd

""" 1. Создание DataFrame """
data = {
    'Имя': ['Анна', 'Борис', 'Виктор'],
    'Возраст': [25, 30, 35],
    'Город': ['Москва', 'СПб', 'Казань']
}
df = pd.DataFrame(data)

""" 2. Чтение данных """
df = pd.read_csv('data.csv')
df = pd.read_excel('data.xlsx')

""" 3. Просмотр данных """
print(df.head())  # Первые 5 строк
print(df.describe())  # Статистика
print(df.info())  # Информация о данных

""" 4. Фильтрация """
adults = df[df['Возраст'] > 25]  # Люди старше 25
moscow_people = df[df['Город'] == 'Москва']

""" 5. Группировка и агрегация """
grouped = df.groupby('Город')['Возраст'].mean()  # Средний возраст по городам

""" 6. Обработка пропусков"""
df = df.dropna()  # Удалить строки с NaN
df = df.fillna(0)  # Заменить NaN на 0

""" 7. Добавление/удаление столбцов """
df['Зарплата'] = [50000, 60000, 70000]
df = df.drop(columns=['Город'])

""" 8. Сохранение """
df.to_csv('new_data.csv', index=False)
```

## TensorFlow

Это открытая библиотека машинного обучения, разработанная Google.

Основные применения:

Практические сценарии использования:
- Распознавание рукописного текста (банки, почта)

- Голосовые ассистенты и распознавание речи
- Автономные транспортные средства
- Фильтрация спама в почте
- Генерация субтитров к видео
- Анализ рыночных тенденций

## Haystack
<!-- junior 3525480 -->
Это open-source фреймворк на Python для создания приложений с семантическим поиском и вопросно-ответными (QA) системами на основе больших языковых моделей (LLM) и извлечения релевантности (RAG — Retrieval-Augmented Generation).

Основные цели:
- Построение RAG-систем — извлечение релевантных документов + генерация ответов.
- Семантический поиск — поиск по смыслу, а не ключевым словам.
- Вопросно-ответные системы над собственными документами.
- Анализ документов (PDF, Word, веб-страницы, базы данных).

## CrewAI
