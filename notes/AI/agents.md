# Agents

## Что такое Агент
<!-- junior 3525480 -->
Это интеллектуальные системы, где языковая модель (LLM) выступает в роли "мозга", который самостоятельно решает, какие действия выполнить и в каком порядке, чтобы ответить на запрос пользователя или выполнить задачу.

В отличие от цепочек (Chains), где последовательность действий жестко запрограммирована, агенты динамически планируют свои действия на основе:
* Запроса пользователя
* Доступных инструментов (Tools)
* Промежуточных результатов выполнения

## Базовые компоненты агента
<!-- junior 3525480 -->
* LLM — принимает решения
* Tools — инструменты для выполнения действий (поиск, вычисления, API-вызовы)
* Агентский исполнитель (AgentExecutor) — управляет циклом "думать-действовать"
* Prompt-шаблон — инструкции для модели о формате reasoning

## Типы агентов в LangChain
<!-- junior 3525480 -->
| Тип агента | Особенности | Использование |
|-----------|-------------|---------------|
| **Zero-shot ReAct** | Универсальный, не требует примеров | Большинство задач |
| **Conversational** | Оптимизирован для диалогов | Чат-боты, поддержка |
| **Self-ask with search** | Специализирован для поиска | Fact-checking, исследования |
| **Structured Input** | Работает со структурированными данными | Анализ таблиц, JSON |
