# Функции

## Общие сведения
Результат функции может быть именованным, тогда создаются локальные переменные с нулевыми значениями их типов.  
Тип функции иногда называют ее сигнатурой.  
Имена параметров и результатов не влияют на тип функции (так как нет значений по умолчанию).  
Аргументы передаются в функцию по значению (если не передается ссылка).  
Вариативные функции (variadic func) - функции с переменным количеством аргументов.

## Defer
Аргументы отложенной функции вычисляются немедленно, но сама функция выполняется позже.   
Defer запускается перед return.  
Если в функции несколько defer, они выполняются в порядке LIFO.  
С помощью defer можно изменять возвращаемое значение:
```go
fmt.Println(x()) // 1

func x() (res int) {
	defer func() { res += 1 }()
	return 0
}
```

## Глубина рекурсии
Фиксированный размер стека ограничивает глубину рекурсии (может случиться переполнение стека, в го стек переменного значения).
По умолчанию максимальный размер стека в Go ~1–2 МБ для 64-битных систем (может варьироваться в зависимости от версии Go и ОС). Это позволяет примерно 1000–10000 вложенных вызовов (зависит от размера фрейма стека каждой функции).
```go
import "runtime/debug"
debug.SetMaxStack(64 * 1024 * 1024) // увеличение стека до 64 МБ
```
Хвостовая рекурсия в Go не оптимизируется (в отличие от некоторых других языков) Если нужна глубокая рекурсия, лучше использовать итеративный подход или срезы/карты для эмуляции стека.

В функции с именованным результатом аргументы у оператора `return` могут быть опущены - пустой возврат (bare return).

Функции являются значениями первого класса - значения имеют тип и их можно передавать.

Функции являются ссылочными типами так как они часто передаются как аргументы и копирование всего их кода и контекста было бы не эффективно.

## Замыкания
Ссылки на переменные: Замыкания хранят ссылки на переменные, а не их копии.  
Переменные, захваченные замыканием, существуют до тех пор, пока существует само замыкание.  
Замыкания часто используются в Go для отложенных вычислений, создания генераторов, реализации callback-функций, инкапсуляции состояния.  

## "naked" return
Пустой `return` вернет переменные объявленные в объявлении функции в блоке возврата.  

## Methods
Метод ничем не отличается от функции, он лишь удобен для документирования доступных для работы функций.  
Метод можно создать для любых типов, объявленных в том же пакете (для встроенных типов нельзя).  
Методы могут принимать указатели на типы в качестве рессивера.  
Метод может быть объявлен для любого именованного типа, определенного в том же пакете, лишь бы его базовый тип не являлся ни указателем, ни интерфейсом.  
Нельзя объявить метод для типа который является указателем (например для `X` где `type X *int`).

Именованные типы могут получить методы базового типа если он будет встроен и именованный:
```go
type cache struct {
	sync.Mutex
	mapping map[string]string
} // cache получит методы sync.Mutex
```

Метод может быть значением и выражением ().

## First-class functions
В Go термин "функции первого порядка" (first-class functions) означает, что функции являются объектами первого класса, то есть они:
* Могут быть присвоены переменным
* Могут передаваться как аргументы другим функциям
* Могут возвращаться из других функций
* Могут храниться в структурах данных (например, в массивах или картах)
