# Slice

## Что такое срез
<!-- junior 3525480 -->
Срез это легковесная структура данных, которая предоставляет доступ к подпоследовательности элементов массива (или ко всем элементам), известного как базовый массив.

Срез состоит из трех компонентов: указателя, длинны и емкости. Указатель указывает на первый элемент массива доступный через срез. Длинна это количество элементов массива, она не может превышать емкость. Емкость как правило показывает количество элементов между началом среза и концом базового массива.
```go
type slice struct { // представлен в го как структура
    array unsafe.Pointer // указатель на первый элемент в массиве
    len   int            // текущая длина
    cap   int            // емкость (максимальная длина без переаллокации)
}
```

Емкость среза массива определяется длинной массива:
```go
var a [12]int
s := a[4:7] // len=3 cap=9
```

Пустой слайс равен `nil` однако пустой инициализированный нет:
```go
var s []int // s == nil
s2 := []int{} // s2 != nil
// Поэтому лучше проверять длину: len(s) == 0, len(s2) == 0
```

## Расширение среза
<!-- junior 3525480 -->
"Срезание" за пределами `cap(s)` вызывает аварийную ситуацию, а срезание за пределами `len(s)`
```go
a := [3]int{1, 3, 5}
s := a[:2] // [1 3]
fmt.Println(s[:3]) // [1 3 5]
```
## Append
<!-- junior 3525480 -->
Добавление в слайс изменяет исходный массив (а так же другие слайсы ссылающиеся на этот массив).
```go
a := [5]int{1,2,3,4,5}
s := a[1:3]
s = append(s, 0) // a=[1 2 3 0 5] s=[2 3 0]
```
Если при добавлении места в исходном массиве нет, то создается новый массив.
```go
a := [3]int{1, 2, 3}
s := a[1:3]
s = append(s, 5) // a=[1,2,3] s=[2,3,5]
```

Если в underlying массиве есть достаточно места (capacity > len), append просто добавляет элементы и увеличивает длину среза.
Если места недостаточно, то создается новый массив с увеличенной емкостью (обычно в 2 раза больше, но это деталь реализации) и в него копируются старые элементы, а потом вставляются новые.
Предварительное выделение памяти:
```go
s := make([]int, 0, 100) // len=0, cap=100
for i := 0; i < 100; i++ {
    s = append(s, i) // Не будет переаллокаций
}
```

Расширение слайса без append вызовет панику:
```go
s := make([]int, 0, 5)
s[10] = 8 // panic: runtime error: index out of range [10] with length 0
```

Копирование слайса с помощью append:
```go
original := []int{1, 2, 3, 4, 5}
copySlice := append([]int(nil), original...)
```

## Алгоритм расширения емкости
<!-- junior 3525480 -->
Если есть свободная емкость (len < cap):
* Новый элемент добавляется в свободное место
* Длина увеличивается на 1
* Емкость не изменяется

Если емкость исчерпана (len == cap):
* Создается новый массив с большей емкостью
* Все элементы копируются в новый массив
* Добавляется новый элемент
* Возвращается новый срез, ссылающийся на новый массив

Стратегия увеличения емкости:
* Для срезов с cap < 1024 - текущая емкость * 2
* Для срезов с cap ≥ 1024 - текущая емкость * 1.25 (увеличение на 25%)

Для "тяжелых" типов данных стратегия изменяется - Для int64 емкость растет медленнее чем для int32.  
https://github.com/golang/go/blob/master/src/runtime/slice.go#L289

## Copy
<!-- junior 3525480 -->
Используется для копирования элементов из одного слайса в другой. Функция возвращает количество скопированных элементов, которое равно минимуму из длин dst и src.

Копирование происходит только в существующие элементы - copy не изменяет размер целевого слайса:
```go
dst := make([]int, 3)
src := []int{1,2,3,4,5}
n := copy(dst, src) //dst=[1 2 3] n=3 
```

Можно копировать между разными частями одного слайса - поддерживается перекрытие областей:
```go
a := []int{1, 2, 3, 4, 5}
copy(a[2:], a[1:4]) // копирует [2 3 4] в позиции начиная с индекса 2
fmt.Println(a)      // [1 2 2 3 4]
```

Чтобы проверить, что срез пустой нужно использовать `len(s) == 0` но не `s == nil`.
