# Array

## Что такое массив
Это структуры данных, которые хранят фиксированное количество элементов одного типа. Можно менять элементы, но нельзя менять длину.  
Они хранятся в непрерывной области памяти, поэтому адрес любого элемента вычисляется за константное время.

## Способы объявления массива
```go
// Способ 1: Объявление с последующей инициализацией
var arr1 [2]bool
arr1[0] = true
arr1[1] = false

// Способ 2: Инициализация при объявлении
arr2 := [3]int{1, 2, 3}

// Способ 3: Автоматическое определение длины
arr3 := [...]int{1, 2, 3, 4, 5}

// Способ 4: Инициализация с указанием индексов
arr4 := [5]int{1: 10, 3: 30}

// Способ 5: Многомерный массив
matrix := [2][3]int{{1, 2, 3}, {4, 5, 6}}

// Способ 6:
arr6 := [5]int{}
```

## Работа с массивами
Длинна массива тоже является частью его типа.
```go
q := [3]int{1, 2, 3}
q = [2]int{4, 5} // ошибка компиляции, q имеет тип [3]int
```
Пустые значения массива будут проставлены автоматически значениями по умолчанию для выбранного типа:
```go
items := [...]int{5:9} // [0 0 0 0 0 9]
elems := [5]int{5, 9} // [5 9 0 0 0]
```
Go передает массивы по значению (value type), а не по ссылке как это неявно делают другие языки.
```go
arr1 := [3]int{1, 2, 3}
arr2 := arr1  // происходит полное копирование всех элементов
```
Массивы можно сравнивать, если они одного типа
```go
a := [2]int{1, 2}
b := [2]int{1, 2}
fmt.Println(a == b)  // true
```

## Хранение массива
Размещение на стеке — небольшие массивы обычно размещаются в стеке, а не в куче.
