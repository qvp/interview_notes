# Generics

## Основные концепции
<!-- junior 3525480 -->
Дженерики (обобщённое программирование) были добавлены в Go начиная с версии 1.18 (2022 год).

1. **Объявление дженериков**:
    - Используются квадратные скобки `[]` для указания типов-параметров
    - Типы-параметры указываются перед обычными параметрами функции

```go
func PrintSlice[T any](s []T) {
    for _, v := range s {
        fmt.Println(v)
    }
}
```

2. **Использование**:
    - Можно явно указать тип или позволить компилятору вывести его

```go
PrintSlice[int]([]int{1, 2, 3})  // Явное указание типа
PrintSlice([]string{"a", "b"})   // Вывод типа компилятором
```

## Типовые ограничения (Constraints)
<!-- junior 3525480 -->
Go использует интерфейсы для ограничения возможных типов:

```go
func Sum[T ~int | ~float64](nums []T) T {
    var sum T
    for _, num := range nums {
        sum += num
    }
    return sum
}
```

Можно определять именованные ограничения:

```go
type Number interface {
    ~int | ~float32 | ~float64
}

func Sum[T Number](nums []T) T {
    // ...
}
```

## Дженерики с типами
<!-- junior 3525480 -->
Можно создавать обобщённые структуры:

```go
type Stack[T any] struct {
    items []T
}

func (s *Stack[T]) Push(item T) {
    s.items = append(s.items, item)
}

func (s *Stack[T]) Pop() T {
    item := s.items[len(s.items)-1]
    s.items = s.items[:len(s.items)-1]
    return item
}
```

## Особенности реализации в Go
<!-- junior 3525480 -->
1. **Мономорфизация**: Компилятор генерирует конкретные реализации для каждого используемого типа
2. **Ограниченная поддержка**: Нет специализации, нет шаблонных методов (только шаблонные типы)
3. **Сравнение с другими языками**: Более ограниченные, чем в C++ или Rust, но более безопасные

## Когда использовать
<!-- junior 3525480 -->
Дженерики полезны для:
- Коллекций (стэки, очереди, деревья)
- Алгоритмов (сортировка, поиск)
- Утилитных функций (минимум/максимум, сравнение)

Но не стоит злоупотреблять - если можно обойтись интерфейсами, лучше использовать их.

## Пример из стандартной библиотеки
<!-- junior 3525480 -->
Пакет `slices` использует дженерики:

```go
import "slices"

func main() {
    s := []int{3, 1, 2}
    slices.Sort(s)
    fmt.Println(s) // [1 2 3]
}
```

## ~
<!-- junior 3525480 -->
Символ `~` (тильда) перед типом в объявлении интерфейса-ограничения (constraint) для дженериков означает, что в качестве типа-параметра можно использовать не только указанный тип, но и все типы, чьё базовое представление (underlying type) соответствует указанному типу.
