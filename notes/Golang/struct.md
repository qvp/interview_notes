# Struct

## Особенности структур
Структуры не могут содержать сами себя, однако могут содержать ссылку на себя (например для создания связанных списков).
Ширина структуры равна сумме ширины составляющих их типов плюс подгонка (padding).  
Структуры могут быть вложенными (анонимные поля).

Дескриптор поля - строка метаданных:
```go
type Point struct {
	X int `json:point_x`
}
```

## Пустая структура
Компилятор Go оптимизирует такие структуры, и при создании переменных типа struct{} или при использовании её в каналах, мапах и слайсах, она не занимает дополнительной памяти.  
Пустая структура тоже является типом.
```go
var x [1000000000]struct{}
fmt.Println(unsafe.Sizeof(x)) // prints 0
```

## embedded
Встраивание структур в Go предоставляет удобный способ реализации композиции вместо классического наследования.  
Методы встроенной структуры "поднимаются" (promoted) во внешнюю структуру.  
Если у внешней и встроенной структур есть поля/методы с одинаковыми именами, приоритет у внешней структуры. Для доступа к "скрытым" полям нужно использовать полный путь.
